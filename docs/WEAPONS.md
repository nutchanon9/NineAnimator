# ชุดอาวุธ (Weapon sets)

NineAnimator มีชุดอาวุธ 6 แบบ แต่ละแบบมีโมเดลให้ดูในเว็บ (เลือกได้จากเมนูใต้ภาพ) และมีท่าสำเร็จรูปในเมนู **ท่าสำเร็จรูป > อาวุธ: ...**
ท่าทั้งหมดในชุดนี้ออกแบบใหม่เองทั้งหมด

| อาวุธ | มือขวา (`Handle`) | มือซ้าย (`LeftHandle`) | ท่าสำเร็จรูป | Marker |
|---|---|---|---|---|
| ดาบยาว | ดาบ (จับสองมือ) | - | ท่าตั้ง, ฟันลง-แทง-ฟันขึ้น, หมุนตัวฟัน, ชักดาบฟันเร็ว | `Hit` |
| ดาบคู่ | ดาบสั้นเล่มที่ 1 | ดาบสั้นเล่มที่ 2 | ท่าตั้ง, ฟันสลับรัว, หมุนตัวฟัน, พุ่งฟัน, ฟันเสยขึ้น | `Hit` R / L / X / Up |
| ดาบใหญ่ | ดาบใหญ่ (จับสองมือ) | - | ท่าตั้ง, ชาร์จแล้วฟาด, กวาดแนวนอน, กระแทกไหล่ | `Charge` start/full, `Hit` |
| ปืนใหญ่ | ปืน (มือซ้ายประคอง) | - | เล็ง, ยิง 3 นัด, บรรจุกระสุน, หมอบยิงต่อเนื่อง (loop), ฟาดพานท้าย | `Fire`, `Reload`, `Hit` |
| ธนู | (Part เล็กๆ หรือลูกธนู) | คันธนู | ยิงธนู, ยิงรัว 3 ดอก, ง้างนานยิงแรง, ยิงโค้งขึ้นฟ้า | `Shoot`, `Charge` |
| ดาบโล่ | ดาบสั้น | โล่ | ยกโล่กัน, รับแรงกระแทก, ฟัน 2 ครั้ง + กระแทกโล่, กระโดดฟัน, ถอยหลังฟัน | `Hit`, `Land`, `Move` |

## อาวุธสองมือ: ให้มือซ้ายจับด้ามเอง

ดาบยาว ดาบใหญ่ และปืนใหญ่ จับด้วยมือขวาที่ `Handle` ส่วนมือซ้ายแค่จับตามไป ไม่ต้องมีข้อต่อของตัวเอง
- **ในท่าสำเร็จรูป:** แขนซ้ายถูกคำนวณให้จับด้ามพอดีทุกคีย์ (ใช้ IK)
- **ตอนทำท่าเอง:** ขยับมือขวาและอาวุธให้ได้ท่าก่อน แล้วกดปุ่ม **มือซ้ายจับอาวุธ** (แผง "ทั้งตัว ณ เวลานี้") ระบบจะหมุนแขนซ้ายให้มือไปจับด้ามที่คีย์เฟรมนั้น ถ้าเอื้อมไม่ถึงจะมีข้อความบอก ให้ดึงอาวุธเข้าหาลำตัวอีกนิด

จุดที่มือซ้ายจับ (นับจากมือขวา):
- **ดาบยาว:** ต่ำลงไปตามด้าม 0.6 stud
- **ดาบใหญ่:** ต่ำลงไปตามด้าม 0.7 stud
- **ปืนใหญ่:** ใต้ตัวปืน หน้ามือขวา 0.6 stud

## ทำ Tool ใน Roblox ให้ตรงกับท่า

1. Part หลักต้องชื่อ `Handle` และแนวของอาวุธ (ใบดาบ) ต้องชี้ไปทางแกน **+Y ของ Handle** ทำแบบนี้แล้ว ตอนถือปกติใบดาบจะชี้ไปข้างหน้าเหมือนในเว็บ
   - ปืนใหญ่ ให้ลำกล้องชี้ไปทาง **−Z ของ Handle** และให้ Handle เป็นด้ามจับแนวตั้ง
   - ถ้าโมเดลหันผิดทาง ให้แก้ที่ `Tool.Grip` แทนการหมุนโมเดล ท่าจะยังถูกเหมือนเดิม
2. ชิ้นส่วนอื่นของอาวุธมือขวา ให้ Weld เข้ากับ `Handle`
3. อาวุธมือซ้ายให้ใช้ Part ชื่อ `LeftHandle` (ชิ้นส่วนย่อยให้ Weld เข้ากับ `LeftHandle`) **ห้าม** Weld `LeftHandle` กับ `Handle`
4. ใส่สคริปต์ `WeaponMotor` จาก [GAME_CODE.md ข้อ 4](GAME_CODE.md) ไว้ใน Tool
5. ธนูไม่มีของในมือขวา ให้ทำ `Handle` เป็น Part เล็กๆ โปร่งใส (หรือเป็นลูกธนูก็ได้) แล้วให้คันธนูเป็น `LeftHandle`

จะลองบนตัวละครใน Studio ก่อนก็ได้ เลือกตัวละครกับ Tool แล้วกด **ติดอาวุธ (Motor6D)** ใน Plugin จากนั้นกด **▶ ดูบนตัว**

## ใช้ Marker ในโค้ด

```lua
-- ตัวอย่าง: ดาบใหญ่ ชาร์จแล้วฟาด
track:GetMarkerReachedSignal("Charge"):Connect(function(value)
	if value == "full" then
		print("ชาร์จเต็ม") -- เช่น เล่นเสียงหรือเอฟเฟกต์
	end
end)
track:GetMarkerReachedSignal("Hit"):Connect(function(value)
	hitEvent:FireServer(value) -- ทำดาเมจฝั่ง server ดู GAME_CODE.md ข้อ 2
end)

-- ปืนใหญ่: ยิงกระสุนตรงจังหวะ Fire
gunTrack:GetMarkerReachedSignal("Fire"):Connect(function()
	fireEvent:FireServer(mouse.Hit.Position)
end)
```
