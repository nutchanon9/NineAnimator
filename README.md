# NineAnimator

เครื่องมือทำแอนิเมชันตัวละคร Roblox (R6 / R15) แบบฟรี ใช้ง่าย ใช้ได้ทั้งคนและ AI

- **เว็บ editor**: เปิดในเบราว์เซอร์ คลิกชิ้นส่วนตัวละครแล้วลากเพื่อหมุน มีเส้นเวลา คีย์เฟรม easing marker (เช่นจังหวะ "Hit") เงาคีย์ก่อน/หลัง (onion skin) ปรับความเร็วทั้งท่า และใส่ดาบ ธนู หรือโล่ในมือให้ดูได้
- **ท่าสำเร็จรูป 24 ท่า** สำหรับเกม RPG:
  - เคลื่อนที่: ยืน เดิน วิ่ง กระโดด ตก ปีน ว่าย นั่ง (ใช้แทนท่าพื้นฐานของ Roblox ได้เลย)
  - ต่อสู้: ตั้งการ์ด ต่อย เตะ ถือดาบ ฟันดาบ คอมโบดาบ 3 จังหวะ ฟาดหนัก ยกโล่ ม้วนหลบ ยิงธนู ร่ายเวท
  - โดนตี / ตาย และไอเทม / อีโมต: ใช้ไอเทม ก้มเก็บของ โบกมือ
- **ให้ AI ช่วยคิดท่า**: พิมพ์ว่าอยากได้ท่าอะไร (ภาษาไทยได้) เว็บจะสร้าง prompt ให้ก็อปไปวางใน Claude, ChatGPT หรือ Gemini แล้วเอาคำตอบมาวางกลับเข้าเว็บ
- **Plugin สำหรับ Roblox Studio**: วาง JSON แล้วสร้าง KeyframeSequence บนตัวละคร ดูตัวอย่าง และอัปโหลดเอา AnimationId ได้ในที่เดียว ส่งออกท่าเดิมกลับเป็น JSON ไปแก้ต่อก็ได้
- **ไฟล์ท่าเป็น JSON ที่อ่านออก**: หมุนเป็นองศา `[x, y, z]` จึงแก้เองหรือให้ AI เขียนได้ (ดู [docs/FORMAT.md](docs/FORMAT.md))

```
 เว็บ editor  ─┐                         ┌─> ▶ ดูบนตัวใน Studio
               ├─ JSON (nineanimator/1) ─┤
 แชท AI      ─┘        │                 └─> Publish → AnimationId → ใช้ในเกม
                       └─> .rbxmx (ลากเข้า Studio ได้)
```

## เริ่มใช้

### 1. เปิดเว็บ editor

**วิธีที่ง่ายที่สุด:** ดาวน์โหลด repo นี้ (ปุ่ม **Code > Download ZIP**) แตกไฟล์ แล้วดับเบิลคลิก `web/index.html`
ครั้งแรกต้องต่ออินเทอร์เน็ต เพราะต้องโหลด three.js กับฟอนต์

หรือเปิดผ่านเซิร์ฟเวอร์ในเครื่อง:

```bash
npm run serve
```

แล้วเปิด http://localhost:8080

### 2. ทำท่า

| ทำอะไร | วิธี |
|---|---|
| เริ่มจากท่าสำเร็จรูป | เมนู **ท่าสำเร็จรูป…** |
| เลือกชิ้นส่วน | คลิกที่ตัวละคร หรือกดชื่อในแผง **ข้อต่อ** |
| หมุนชิ้นส่วน | ลากชิ้นที่เลือกอยู่ (กด Shift ค้างไว้เพื่อบิด) หรือใช้แถบเลื่อน X/Y/Z |
| เลื่อนเวลา | คลิก/ลากบนเส้นเวลา หรือกดลูกศร ← → |
| ใส่คีย์เฟรม | แค่หมุนชิ้นส่วน ณ เวลาไหนก็ได้ ระบบจะสร้างคีย์ให้เอง หรือกด **+ คีย์เฟรม** (K) |
| ย้ายคีย์เฟรม | ลาก ◆ บนเส้นเวลา |
| สลับท่าซ้าย↔ขวา | ปุ่ม **สลับซ้าย↔ขวา** (M) ใช้ทำท่าเดินหรือวิ่งครึ่งหลังได้เร็ว |
| จังหวะตีโดน | ใส่ marker ชื่อ `Hit` แล้วในเกมใช้ `GetMarkerReachedSignal("Hit")` |
| ดูท่าก่อน/หลัง | ติ๊ก **เงาคีย์ก่อน/หลัง** ใต้ภาพ ตอนหยุดเล่นจะเห็นท่าของคีย์ก่อนหน้า (สีส้ม) และคีย์ถัดไป (สีฟ้า) |
| ทั้งท่าเร็วไป/ช้าไป | ปุ่ม **เร็วขึ้น 20%** / **ช้าลง 20%** ในแผงตั้งค่า |
| ย้อนกลับ | Ctrl+Z / Ctrl+Y |

งานจะเซฟในเบราว์เซอร์อัตโนมัติ ถ้าจะเก็บถาวรให้กด **บันทึก .json**

### 3. เอาเข้า Roblox

ทางที่แนะนำคือใช้ Plugin: ติดตั้งตาม [docs/PLUGIN.md](docs/PLUGIN.md) แล้วกด **คัดลอก JSON** ในเว็บ เอาไปวางใน Plugin กด **สร้าง** แล้วกด **อัปโหลด**

อีกทางคือกด **ส่งออก .rbxmx** แล้วลากไฟล์เข้า Studio จะได้ KeyframeSequence มา จากนั้นคลิกขวาแล้วเลือก Save to Roblox

### 4. ใช้ในเกม

[docs/GAME_CODE.md](docs/GAME_CODE.md) มีโค้ด Luau พร้อมใช้ 3 แบบ:
- เปลี่ยนท่าเดิน วิ่ง กระโดดของตัวละคร
- ทำอาวุธที่ฟันแล้วทำดาเมจตรงจังหวะ `Hit`
- ท่าโดนตีและท่าตายของ NPC

## R6 กับ R15 ต่างกันยังไง

| | R6 | R15 |
|---|---|---|
| ชิ้นส่วน | 6 ชิ้น (หัว ลำตัว แขน 2 ขา 2) | 15 ชิ้น มีศอก เข่า มือ เท้า และลำตัวแยกบน/ล่าง |
| ความรู้สึก | แข็งๆ แบบ Roblox ยุคแรก ทำท่าง่าย ตีแรงชัด | ท่าเป็นธรรมชาติกว่า งอศอกงอเข่าได้ |
| เหมาะกับ | เกมต่อสู้สายคลาสสิก (เช่นแนว battlegrounds หลายเกม) เกม obby | เกม RPG เกมที่ใช้ชุด/ตัวละครแบบใหม่ (Layered clothing, Dynamic heads) |

**เกม RPG ส่วนใหญ่ตอนนี้ใช้ R15** เพราะท่าถืออาวุธ ใช้ไอเทม และท่าเดินวิ่งดูดีกว่า และรองรับ avatar แบบใหม่ทั้งหมด ถ้ายังไม่แน่ใจ แนะนำให้เริ่มที่ R15
ตั้งค่าได้ที่ Game Settings > Avatar > Avatar Type ส่วนในเว็บ ปุ่ม R15/R6 ด้านบนจะแปลงท่าให้ (แปลงจาก R15 เป็น R6 แล้วศอก/เข่าจะหายไป)

## ให้ AI ทำท่า

1. กด **ให้ AI ช่วยคิดท่า** แล้วพิมพ์ท่าที่อยากได้ หรือกดไอเดียสำเร็จรูป
2. กด **คัดลอก prompt** แล้วไปวางในแชท AI
3. ก็อปคำตอบของ AI ทั้งก้อนมาวางในช่องที่ 3 แล้วกด **นำเข้าท่านี้**
4. ปรับต่อด้วยมือ หรือติ๊ก "แนบท่าปัจจุบันไปด้วย" แล้วสั่ง AI ให้แก้ต่อ

AI ที่เขียนโค้ดได้ (เช่น Claude Code) ใช้คำสั่งในเครื่องได้เลย:

```bash
node tools/nine.js prompt R15 "ท่าฟันดาบสองมือ"
```

```bash
node tools/nine.js validate examples/slash.R15.json
```

```bash
node tools/nine.js rbxmx examples/slash.R15.json
```

## สถานะและข้อจำกัด

- เวอร์ชัน 0.2 ทดสอบคณิตศาสตร์และ export ด้วยชุดทดสอบอัตโนมัติ ส่วนหน้าเว็บทดสอบในเบราว์เซอร์แล้ว แต่ **Plugin ยังไม่ได้ลองใน Roblox Studio จริง** (ตรวจได้แค่ว่า syntax ถูก) ถ้าเจอปัญหาแจ้งใน Issues ได้เลย
- ดาบ ธนู และโล่ในเว็บมีไว้ดูภาพเท่านั้น ยังไม่รองรับการขยับอาวุธแยกด้วย Motor6D
- ท่าว่ายน้ำและนั่งออกแบบตามท่าพื้นฐานของ Roblox ซึ่งตัวเกมเป็นคนจัดตำแหน่งตัวละครเอง (ในเว็บจะเห็นนั่งลอยอยู่ เป็นเรื่องปกติ)
- เปิดได้เฉพาะ `.rbxmx` (XML) ยังเปิด `.rbxm` (binary) ไม่ได้ ถ้ามีไฟล์แบบนั้นให้ใช้ Plugin "ส่งออก JSON" แทน
- ยังไม่รองรับ CurveAnimation และ IK
